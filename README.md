# Jaybroski: website concepts

Pre-booking mockups by Distorted Web for Jaybroski (Call of Duty / GTA VI Twitch streamer, Monster Energy creator).
Plain HTML and CSS, no build step. Deploy the repo root as-is (Netlify).

| Path | Concept | Package |
| --- | --- | --- |
| `/` | Chooser page linking all three | n/a |
| `/link/` | Link page (Linktree replacement) | Link Page, from $100 |
| `/one-page/` | One scrolling page with pop-up windows | One-Pager, from $200 |
| `/full/` | Six pages: Home, Live, Videos, Partners, Merch, About | Full Website, from $300 |

Full-site pages are generated by `tools/build_full.py` (edit it, then run `python3 tools/build_full.py`).
